# 会话清理与工作区导出 · dsh-session-cleaner

为 DeepSeek Harness 提供一站式的**对话导出、整工作区压缩包导出、归档对话清理与工作区连根清理**面板。安装后的中文名称为 **会话清理**，入口排在左侧栏“记忆系统”之后。界面采用 Anthropic Claude 风格的克制卡片、衬线标题和 DSH 原生亮暗主题。

## 六大板块功能

| 板块 | 核心能力 |
| --- | --- |
| **1. 已归档对话** | 对应 DSH「视图 → 已归档」中的归档会话，支持单条/批量导出备份或一键清空已归档 |
| **2. 已删除工作区** | 自动识别已从 DSH 移除工作区后遗留在「未分组」中的会话，按原工作区分组展示，支持按组导出 `.zip` 或一键删除 |
| **3. 原本无关联** | 创建时未绑定工作目录（无 `cwd`）或手动标记为无关联的独立会话 |
| **4. 归属待确认** | 供手动归类调整的候选视图 |
| **5. 所有对话** | 汇总本机全部未归档与已归档对话，支持 `全部 / 未归档 / 已归档` 筛选、单条或批量一键导出（`.zip` / `.md` / `.jsonl`）与直接删除 |
| **6. 所有工作区** | 管理当前所有已注册的工作区：支持**一键导出整工作区 `.zip` 压缩包**（包含该工作区下全部对话日志），或**删除工作区及全部对话**（避免变成“未分组”残留） |

## 对话导出与整工作区 `.zip` 打包

- **单条/批量导出对话**：无论对话是否已归档、甚至正在运行中，均可随时点击 **「↓ 导出对话」** 或勾选多条点击 **「↓ 导出所选对话」**。支持 3 种格式：
  1. `Markdown + JSONL (.zip)`（默认）：同时包含可读排版 `transcript.md`、DSH 原始事件流 `events.jsonl` 与 `manifest.json`；
  2. `仅可读对话 (.md)`：包含完整提问、思考过程、工具调用与回复的 Markdown 文档；
  3. `仅原始日志 (.jsonl)`：包含会话 `header` 与全部原始事件行。
- **整工作区一键导出压缩包（`.zip`）**：在「所有工作区」板块点击 **「↓ 导出工作区压缩包 (.zip)」**，立即将该工作区下的所有未归档与已归档对话打包为 `<工作区名>-对话日志-<日期>.zip`，并通过 DSH 桌面端原生保存框或浏览器下载（同时在插件 `runtime/exports/` 下保留备份副本）。

## 在线一键永久删除（对话 & 工作区）

- **删除范围**：卸载内存 `SessionStore` 会话、移除 `workspaceRegistry` 中的归档/置顶/工作区引用与残留幽灵 ID、清理 `sessionPersistence` 内存缓存、删除 `session_projcache` 投影缓存记录与磁盘缓存文件，并删除 `sessions/<projectKey>/<sessionId>` 会话目录（默认连带清理其派生的 subagent 子会话）。在「所有工作区」中点击 **「删除工作区及对话」** 时，还会提供 **「↓ 先导出备份 (.zip) 再删除」** 选项，并同时移除工作区注册与其下全部对话，彻底告别“未分组”残留。
- **绝不触碰本地磁盘项目文件**：严格校验会话目录必须位于 `sessions` 二级子目录内，且与所有工作区及会话的 `cwd` 项目路径无任何交叠；本地硬盘上的代码、文档和项目文件夹 100% 完好保留。
- **运行中保护**：正在运行或等待输入的对话（以及含运行中对话的工作区）自动锁定，防止误删当前活动任务。

## 安装与测试

可通过 DSH CLI 或内置 `plugin_manager` 安装：

```bash
dsh plugin --profile desktop add github:JsaonSpace92/dsh-session-cleaner
```

或在本地克隆仓库后，使用 DSH `plugin_manager` 的 `install_bundle`（`target` 设为本地仓库目录绝对路径）安装。

```bash
npm run check
npm test
```

`0.3.0` 包含 25 项 JavaScript 测试与 30 项 Python 测试，合计 55 项测试全部通过。
